# CryoSat

Cryogenics and orbital infrastructure for [Mekanism](https://github.com/mekanism/Mekanism).

Liquefy air into cryogenic coolants, run superconducting power networks that have to stay cold,
and fuel rockets that put asteroid miners, utility satellites and orbital weapons into orbit.

* Minecraft 1.21.1, NeoForge
* Requires Mekanism 10.7.19 or newer (Mekanism Generators optional)

## Development

```
./gradlew build          # compile and package
./gradlew runClient      # launch a dev client with Mekanism and Generators
./gradlew runServer      # headless dev server
./gradlew runGameTestServer  # run game tests headless, exits with failure if any test fails
./gradlew runData        # data generation into src/generated/resources
```

Playtesting: [docs/testing-guide.md](docs/testing-guide.md).

Textures follow [docs/texture-style-guide.md](docs/texture-style-guide.md) and are generated by
scripts in `tools/textures/`.
